# 无障碍出版工作室 · Braille Studio

本地编排盲文段落与网格化触觉示意图的出版工具。**全部计算在本地完成，不调用任何云服务。**

- **React + TypeScript**：版面编辑（标题、正文、页码、网格化触觉示意图 + 图注）
- **liblouis WebAssembly**：从官方源码构建（`scripts/build-liblouis.sh`），使用**项目固定的指定语言表**（`en-us-g1.ctb` 及其 include 闭包，随 WASM 打包并留存于 `public/vendor/liblouis/tables/`，版本与 sha256 见 `PINNED.md`）
- **Canvas 预览**：逐点绘制点阵；**预览与 PDF 共用同一份版面模型点位**
- **pdf-lib 导出**：真实页面尺寸（mm→pt），每个凸点为实心圆
- **IndexedDB**：工程本地保存/载入

## 工艺参数（题目给定的示例工艺参数，`src/layout/geometry.ts`）

| 参数 | 值 |
|---|---|
| 点阵最小间距（相邻凸点中心距） | **2.5 mm** |
| 方距（相邻盲文 cell 水平中心距） | 6.0 mm |
| 行距 | 10.0 mm |
| 凸点直径 | 1.5 mm |

正文方内点距、示意图网格点距统一采用最小间距 2.5mm；版面校验逐点复核任何两个凸点中心距 ≥ 2.5mm。

## 版面规则

- 行宽以**盲文方（cell）**设置；超过页面可容纳方数时给出错误并按最大值排版
- 长单词超过行宽时按行宽**硬拆分**并给出警告
- 图形 + 图注为**原子块**，放不下整体移到下一页；页码独占末行
- 校验：图形、图注、正文、页码包围盒**两两不重叠**；凸点不出页
- 预览侧栏展示**原文 ↔ 盲文**逐词对应（基于 `lou_translate` 的 outputPos 映射）

## 开发

```bash
npm install
npm run build:liblouis   # 需要 emsdk（EMSDK_DIR 环境变量，默认 /tmp/emsdk）
npm run dev              # 开发服务器
npm test                 # 一致性验证（见下）
npm run build            # 类型检查 + 生产构建
```

`public/vendor/liblouis/` 已提交构建产物，不重新构建也可直接运行。

## 一致性验证（`tests/consistency.test.ts`）

按题目要求，用**长单词**、**数字切换**（⠼ 数字指示符 / ⠰ 字母指示符）和**带图注的页面**验证：

1. 预览场景点位 === 版面模型点位（同源数据）
2. PDF 内容流解析出的圆心 === 版面模型点位（逐点比对，容差 0.05pt）
3. 页面尺寸 = 真实纸张尺寸；点阵最小间距 ≥ 2.5mm；元素不重叠

## ⚠️ 触读质量声明

点位精度只能保证**数字版面**层面一致。**最终触读质量仍需在实际设备上打样确认**：
凸点高度、点形（锥度）、纸张/薄膜厚度、盲文打印机的针压与校准都会影响手感，
本工具输出的 PDF 应在目标 embosser 上打样，由视障读者实际触读验收后再批量生产。
